# Ravenshaw CRM

Next.js 15 CRM for Ravenshaw AI, deployed on Vercel (ravenshaw-crm-6ye2.vercel.app) with Supabase.

## Working with Carson

- Whenever a connector or MCP server would make a task easier, suggest it every time, until Carson says to stop.
- Check Vercel env vars and connected services before asking Carson for keys or setup he may already have done.
- Never paste API keys or secrets in chat.
- Database migrations are additive only. Ask before any destructive database operation.
- Keep answers short and direct.
