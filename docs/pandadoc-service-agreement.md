# Ravenshaw AI — Service Agreement (PandaDoc template)

How to set it up in PandaDoc (about 10 minutes):

1. PandaDoc → Templates → **+ Template** → Blank. Name it **Ravenshaw AI Service Agreement**.
2. Under **Roles**, add one role named exactly **Client** (capital C).
3. Paste the agreement text below. Every `[Like.This]` is a PandaDoc **variable**. Keep the names exactly as written; the CRM fills them in.
4. Where it says **PRICING TABLE**, insert a **Pricing table** block and name it exactly **Pricing Table 1**. Leave it empty; the CRM adds the line items from the deal.
5. At the bottom, add a **Signature** field and a **Date** field assigned to the **Client** role.
6. Save, then in the CRM: Settings → Integrations → PandaDoc → pick **Ravenshaw AI Service Agreement** → Save template.

> This is a starting draft, not legal advice. Have a lawyer licensed in Québec review it before you rely on it.
